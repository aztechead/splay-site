Splay for the iPhone Duo

What you need

An iPhone Duo with iOS 27 or later. Splay works on the front screen in portrait and landscape and makes no changes on the inner screen or on other iPhones.

Turning it on

  1. Open Settings, then Apps, then Safari, then Extensions.
  2. Tap Splay and turn on Allow Extension.
  3. Set All Websites to Allow.

If you'd rather not allow every site, set All Websites to Ask and allow Splay one site at a time.

Turning it off for one site

On that site, tap the page menu button at the left of Safari's address bar, then tap Splay. Splay stays off for that site until you tap it again.

Text styles

The Splay app sets how text meets Safari's buttons. The default justifies text and hyphenates long words, so every line ends at the buttons. Justifying without hyphens also fills each line, though some lines end up with wide gaps between words. Ragged leaves the lines uneven, ending up to a word short of the buttons.

Turn on Run text under the buttons to let lines use the whole width of the screen. Links and buttons are still moved clear of Safari's buttons.

Pages already open update when you go back to Safari.

If a page doesn't look right

  • Check that All Websites is set to Allow, or that Splay is allowed for that site.
  • Reload the page. If you change Safari's page zoom while a page is open, the page needs a reload before it fits again.
  • If a site still looks wrong, turn Splay off for it from the page menu.
